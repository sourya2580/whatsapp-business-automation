# 💬 WhatsApp Business Automation

> An automation tool that streamlines business communications on WhatsApp.

## 📌 Problem
Repetitive manual messaging wastes hours for small businesses — greetings, follow-ups and broadcasts done by hand.

## 💡 Solution
An automation tool that handles routine WhatsApp business communications, reducing manual effort and response time.

## ⚙️ Tech Stack
- **Backend:** Node.js, Express.js
- **Integrations:** WhatsApp Business API / automation APIs

## 🧠 Key Learnings
- Event-driven automation patterns
- Rate limits and API reliability
- Building practical bots for real business use

## 🔧 How to Run
```bash
git clone https://github.com/sourya2580/wa-automation
cd wa-automation
npm install
npm start
```
